A short update, mainly of interest to Nordic users: Sigcharts 2.0 beta We have a new version of Sigcharts which, in addition to the previous Arctic/Norway also covers the Nordic/Baltic regian (minus Iceland). Also, the search interface has been made consistent with the rest of the API: https://api.met.no/weatherapi/sigcharts/2.0/documentation While currently in beta we suggest you start using this after the summer is over. We're not sure how long the current version 1.0 will live, this depends on how soon our regular users will take to implement the new version.
